# What Builds Democratic Connection?

A data-driven analysis of party trust, political efficacy and social confidence in Germany using European Social Survey Round 11 data.

## Problem Statement

This project investigates where democratic connection weakens in Germany. The focus is not only on general satisfaction with democracy, but on trust in political parties, perceived political efficacy, social trust and political participation.

## Data Source

European Social Survey Round 11 integrated file, Germany subset.

- Full ESS11 dataset: 50,116 respondents
- Germany subset: 2,420 respondents
- Extended clean analysis dataset: 2,004 respondents
- Raw format: SPSS `.sav`
- Analysis tools: Python, pandas, matplotlib

Raw ESS data is not included in this repository. It can be downloaded from the official ESS Data Portal.

## Current Status

- Loaded and inspected ESS11 integrated data
- Filtered Germany subset
- Built clean working datasets
- Created social trust and political efficacy indices
- Identified early patterns in party trust, voting behavior, political efficacy and social trust
